ESP32 Oref Alert LED

Pikud Haoref Standalone Alert Sensor

Flash the firmware to your ESP32-S3 directly from the browser.
Connect via USB and click the button below.

Your browser does not support Web Serial.
Use Chrome or Edge. Serial access denied.

After Installation

  1. The Wi-Fi setup dialog will appear -- enter your network credentials
  2. Open http://oref-alert.local/ to configure the alert zone
  3. The LED turns green when monitoring

התקינו את הקושחה על ה-ESP32-S3 ישירות מהדפדפן.
חברו בכבל USB ולחצו על הכפתור.

הדפדפן לא תומך ב-Web Serial.
השתמשו ב-Chrome או Edge. גישה לחיבור טורי נדחתה.

אחרי ההתקנה

  1. יופיע חלון הגדרת Wi-Fi -- הכניסו את פרטי הרשת
  2. פתחו http://oref-alert.local/ כדי להגדיר את אזור ההתרעה
  3. הנורית תידלק ירוק כשהמערכת מנטרת

Requires Chrome or Edge on desktop. ESP32-S3 with USB.
